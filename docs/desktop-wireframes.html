Card issuers

For the demo, yes: Bridge's sandbox issues test Visa cards that spend Solana devnet USDC. For real cards, no provider lets a company issue just by depositing USDC.

Every production program needs our company verified (KYB), a signed card program with an issuer, and KYC for each cardholder. Once that's in place, the user side is exactly what you described: the card spends straight from USDC in their wallet.

Getting Bridge sandbox cards: yes, we need accounts

  1. Bridge developer account. Bridge's quick-start says to email support@bridge.xyz to be onboarded, then generate a sandbox API key in the Bridge Dashboard. This is the step that can take days.
  2. Stripe account with a Stripe Sandbox (free signup; Stripe's older Test Mode is not supported), then install the Bridge Cards app from the Stripe Marketplace on that sandbox.
  3. Link them with POST /v0/cards/enable (Stripe account id, program_type: "consumer").
  4. Create a test customer with the cards endorsement, then create cards and simulate payments in Stripe. Non-custodial cards on Solana devnet are supported.

Sandbox needs no real company verification, but step 1 is gated by Bridge. Email today; until keys arrive the mock card service stays the default.

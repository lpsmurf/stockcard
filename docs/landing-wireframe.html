Shared components and constraints

Reused everywhere
  • <WaitlistForm /> ×2
  • <NumberTicker /> ×3
  • <ScrollReveal /> all sections
  • <StatusLine /> wherever a card or benefit appears
  • <MetalCard /> hero + tiers
Client vs server
  • Only the calculator, marquee, tier switcher, FAQ and forms are client components
  • Everything else is a server component reading static data files
  • The page never connects a wallet
Budget
  • Lighthouse mobile ≥ 90 perf, ≥ 95 a11y
  • LCP < 2.5s on 4G
  • 360px minimum, no horizontal scroll
  • prefers-reduced-motion honoured
